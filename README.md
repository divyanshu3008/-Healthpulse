# 🏥 HealthPulse

HealthPulse ek healthcare management web application hai jo maine learning purpose aur real-world healthcare workflow ko samajhne ke liye develop kiya hai.
Is project me patient management, disease prediction, hospital resources aur dashboard system jaise features implement kiye gaye hain using **Flask** and **Machine Learning**.

Mera focus sirf backend functionality nahi tha, balki ek simple aur user-friendly interface banana bhi tha jise easily use kiya ja sake.

---

# 🚀 Features

* Patient Login & Registration
* Disease Prediction Module
* Doctor Dashboard
* Patient Reports
* Hospital Resources Section
* OTP Verification
* Vaccination Information
* Interactive UI

# ⚙️ How to Run the Project

## Clone the Repository

```bash
git clone https://github.com/divyanshu3008/-Healthpulse.git
```

## Move to Project Folder

```bash
cd -Healthpulse
```

## Install Required Libraries

```bash
pip install -r requirment.txt
```

## Run the Application

```bash
python app.py
```

After running the project, open this in your browser:

```bash
http://127.0.0.1:5000
```
